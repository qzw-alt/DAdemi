# Chatbot 项目说明

> 给小德米用的

## 位置
`C:\Users\csdm2\.openclaw\workspace\for-xiaodemi\chatbot`

## 需要配置

1. **API Key**
   - 复制 `.env.example` 为 `.env`
   - 添加 OpenAI API Key

2. **安装**
   ```bash
   pnpm install
   ```

3. **运行**
   ```bash
   pnpm dev
   ```

## 功能
- AI 聊天机器人
- 支持代码、文档、图片生成
- 用户登录/注册
- 聊天历史保存

## 部署
- Vercel Ready
- 需要数据库（PostgreSQL）
