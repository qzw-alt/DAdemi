# 技能精通化实施方案

> 来源：小德米 2026-03-04

## 核心思路

从"单技能碎片化使用" → "工作流自动化"

## 三步走

1. **Day 1-2**: 建立技能矩阵 skill-matrix.md
2. **Day 3-4**: 设计工作流模板 (research, content, dev)
3. **Day 5-7**: 实现智能推荐 (意图识别 + 执行器)

## 目标

- 工作流使用：0 → 5+/周
- 单任务效率：5分钟 → 2分钟
- 技能组合率：10% → 60%+

## 3大工作流

1. **research**: multi-search → tavily → summarize → doc
2. **content**: research → lenny-skills → write → edit
3. **dev**: exec → agent-browser → doc-write
