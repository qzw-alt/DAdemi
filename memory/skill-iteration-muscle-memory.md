# 🔄 技能迭代肌肉记忆

> 同样的功能，只留最好用的
> 对比 → 优选 → 淘汰 → 遗忘旧的
> 日期：2026-03-15

---

## 核心原则（必须背诵）

```
当有两个技能做同样的事时：
1. 同场景对比测试
2. 选出更好的那个
3. 淘汰差的那个
4. 忘掉旧的，只用新的
```

**为什么重要**：
- 技能太多 = 选择困难 = 不用
- 只留最好的 = 条件反射 = 快
- 不断迭代 = 越来越顺手

## 技能迭代决策流程（肌肉记忆）

```
发现新技能做同样的事
        ↓
   问自己3个问题：
        ↓
1. 比现有的快吗？
2. 比现有的稳定吗？  
3. 比现有的功能多吗？
        ↓
   如果2个YES → 安装对比测试
        ↓
   同一场景测试3次
        ↓
   记录结果（时间/质量/稳定性）
        ↓
   选出 winner
        ↓
   淘汰 loser
        ↓
   更新此文档
        ↓
   忘掉 loser 的存在
```

## 技能-场景映射（最新版）

| 场景 | 触发词 | 使用技能 | 不用别的 |
|------|--------|---------|---------|
| 快速搜索 | "搜一下" | multi-search-engine | web-search |
| 深度调研 | "详细查" | tavily-search | - |
| 写文档交付 | "写个文档" | feishu-doc | write |
| 本地改文件 | "改一下" | write/edit | - |
| 测试网站 | "看一下" | browser (内置) | - |
| 询单来了 | "新询单" | inquiry-timer.sh | - |
| 发博客前 | "检查" | blog-publish-checklist.sh | - |

**禁止行为**：
- ❌ 同一个场景用两个技能
- ❌ 技能效果一样却都留着
- ❌ 新技能来了不对比就加
