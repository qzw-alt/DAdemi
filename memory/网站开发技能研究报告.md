# 网站开发技能研究报告

> 调研时间：2026-03-04

---

## 1. WordPress CLI (wp-cli)

### 是什么？
WordPress 命令行工具，可以不登录后台管理网站

### 能做什么？
- 安装/更新 WordPress
- 插件/主题管理
- 数据库操作
- 用户管理
- 文章发布

### 常用命令
```bash
wp core install --url=example.com --title=MySite --admin_user=admin --admin_password=pass --admin_email=email@example.com
wp post create --post_title="Hello World" --post_status=publish
wp plugin install woocommerce --activate
```

### 学习难度：⭐⭐ 中等

---

## 2. Cloudflare API

### 是什么？
通过代码管理域名DNS、SSL、CDN

### 能做什么？
- DNS记录自动管理
- 自动申请/续期SSL证书
- CDN缓存刷新
- 域名解析

### 常用操作
```bash
# DNS记录管理
curl -X POST "https://api.cloudflare.com/client/v4/zones/:id/dns_records" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{"type":"A","name":"example.com","content":"1.2.3.4"}'
```

### 学习难度：⭐⭐⭐ 较难（需要API基础）

---

## 3. Docker 自动化部署

### 是什么？
容器化技术，打包网站环境和代码

### 能做什么？
- 快速环境搭建
- 一键部署
- 环境隔离
- 弹性扩展

### 常用命令
```bash
docker build -t my-wordpress .
docker run -d -p 80:80 my-wordpress
docker-compose up -d
```

### 学习难度：⭐⭐⭐ 中等
