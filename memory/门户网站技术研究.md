# 门户网站技术研究（2026-03-05）

## 一、门户网站技术架构

### 主流技术方案

| 技术方案 | 特点 | 适用场景 |
|----------|------|----------|
| **WordPress** | 最流行(全球40%网站)、主题插件丰富、易上手 | 博客、企业站、门户网站 |
| **ThinkPHP** | 国内流行、简单高效、文档完善 | 分类信息站、门户 |
| **Laravel** | 优雅、现代、扩展性强 | 高端定制站 |
| **SpringBoot+Vue** | 前后端分离、功能强大 | 复杂系统 |

### WordPress 门户网站架构（推荐）

```
前端层：React/Vue.js + 响应式主题
应用层：WordPress核心 + 插件
数据层：MySQL/MariaDB
```

**推荐插件：**
- 多站点(MU) - 一个后台管多个站点
- WooCommerce - 电商功能
- ACF - 自定义字段
- Yoast SEO - SEO优化

## 二、AI搜索习惯分析

### AI如何抓取网站内容？

1. **传统搜索**：爬虫抓取 → 索引 → 排名
2. **AI搜索**：理解页面含义 → 提取结构化数据 → 生成答案

### 门户网站 vs 个人博客

| 对比项 | 门户网站 | 个人博客 |
|--------|----------|----------|
| **内容丰富度** | 高（多商家/多分类） | 低（单一作者） |
| **更新频率** | 高（用户贡献） | 中等 |
| **权威性** | 中等 | 高（专业个人品牌） |
| **AI抓取倾向** | 综合性问题优先 | 专业深度内容优先 |

### 关键结论

**AI更愿意从哪种获取？**

1. **个人博客/网站** - 如果内容专业、深度，AI更容易引用
2. **门户网站** - 如果是综合性信息（本地服务、分类信息），AI也会抓取

**商业机会**：
- 帮商家建**独立博客/网站** → AI搜索能搜到
- 帮商家在**门户网站**发布 → 扩大曝光
