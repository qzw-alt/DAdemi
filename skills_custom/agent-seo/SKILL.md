# SEO分析 Skill

## 功能

1. **关键词分析** - 检查文章关键词密度和分布
2. **SEO评分** - 评估文章SEO效果
3. **meta标签检查** - 检查标题、描述
4. **可读性分析** - 评估文章可读性

## 使用方法

### 分析关键词密度

检查文章是否包含目标关键词：

```
目标关键词: "medical tourism China"
检查位置:
- H1 标题 (必须包含)
- 第一段 (必须包含)
- H2/H3 小标题 (建议包含)
- 正文 (1-2% 密度)
```

### SEO检查清单

| 检查项 | 要求 |
|--------|------|
| H1标题 | 包含核心关键词 |
| Meta描述 | 150-160字符，包含关键词 |
| 关键词密度 | 1-2% |
| 图片Alt | 包含关键词 |
| 内部链接 | 2-3个 |
| 外部链接 | 1-2个权威网站 |
| 字数 | 1500+ |

### 医疗旅游常用关键词

**核心词:**
- China medical tourism
- Medical tourism China
- Affordable surgery China

**长尾词:**
- knee replacement cost China
- hip replacement surgery China
- heart surgery cost China
- best hospitals in China

**地域词:**
- medical tourism Beijing
- medical tourism Shanghai
- medical tourism Guangzhou
